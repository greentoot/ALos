Depose tes ROMs ici.

Formats supportes automatiquement au build:
- un fichier `.gb`, `.gbc`, `.gba`, `.nds`, `.3ds` ou `.cia` directement dans ce dossier
- un sous-dossier contenant une ROM
- un `.zip` contenant une ROM compatible
- un cover PNG optionnel nomme cover.png

Exemples:
- gba_library/PokemonRouge.gb
- gba_library/PokemonOr.gbc
- gba_library/PokemonEmeraude/Pok_mon_Emeraude.gba
- gba_library/PokemonDiamant/PokemonDiamant.nds
- gba_library/PokemonX/PokemonX.3ds
- gba_library/PokemonEmeraude/cover.png

Ensuite:
- make all
- make run
